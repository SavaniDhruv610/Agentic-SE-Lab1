## What I think about AI in software engineering today
AI speeds up scripting, log analysis and configuration work, which is very useful in DevOps. However, generated code can contain insecure patterns or outdated dependencies without any warning. Security review and testing remain essential, no matter who or what wrote the code.

## Where software engineering will be in 5–10 years
Pipelines will increasingly build, test and deploy with AI agents, while humans set the guardrails. Security and compliance will become a core part of every engineer's job, because automated code also means automated mistakes.

## My hot take on AI
Every line of AI-generated code is a security review waiting to happen.
